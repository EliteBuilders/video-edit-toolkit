## Color

| Token | Hex | Use |
|---|---|---|
| Ground | `#0F1626` | Every full-frame graphic. Darker is fine. |
| Ground deep | `#0A0E18` | Vignette edges, outer falloff |
| Accent | `#3B82F6` | The only accent. Bars, rules, chip borders, underlines |
| Accent glow | `#7BC8FF` | Glow, picked-out phrases in a title, chip numerals |
| Proof | `#F59E0B` | Highlighter swipe on a cited claim. Nothing else |
| Gain | `#34D26A` | The upper series in a two-line chart. Nothing else |
| Negate | `#EF4444` | Strikethrough only. Never a fill, never a border |
| Text | `#FFFFFF` | All graphic text |

Never green or purple as an accent. Semantic colors never become decoration.

## Type

| Role | Face | Weight |
|---|---|---|
| Display / headline | Archivo Black | 400 (it ships one weight) |
| Functional / captions / labels | Inter | 700 to 900 |
| Emphasis + section titles | Playfair Display Italic | 600 |

**Serif rule:** italic serif goes on one word or a short phrase inside a sans line, and on section title cards. Never on functional text. Never a whole sentence in serif.

## Layout zones

Everything that overlays the host has an assigned zone so components never collide.

| Zone | Owner |
|---|---|
| Bottom center | Captions. Nothing else, ever |
| Bottom left | Lower third, attribution card |
| Bottom strip, full width | List chips |
| Top left | Source identity chip |
| Center frame | Full-frame graphics only, never over a talking head |

## Ground rule

Dark ground for anything overlaying a talking head. The one exception is a full-frame screen composite, which sits on a lit blue accent glow. Never a light ground under an overlay.
