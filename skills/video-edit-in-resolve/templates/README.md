# Project templates

Copy these into a video project folder before the first edit.

```bash
mkdir -p ~/Video/<project>/{raw,output,assets,reference,graphics/kit,broll/candidates}
cp ~/Projects/Work/youtube-toolkit/skills/video-edit-in-resolve/templates/{BRAND.md,BROLL.md,CREATIVE-BRIEF-TEMPLATE.md,FIRST-RUN.md} ~/Video/<project>/
```

Then run the `video-edit-creative-brief` skill in that folder to fill in `BRAND.md` and produce `CREATIVE-BRIEF.md`.

`BRAND.md` here is a blank to fill in. **For a client, do not copy it.** Let the brief skill build theirs from scratch.
